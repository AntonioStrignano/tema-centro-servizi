# Verifica Visibilita Font

Checklist operativa per controllare quali font si vedono correttamente nel tema.

Istruzioni rapide:
- Metti `x` in una sola colonna tra `Si vede` e `Non si vede`.
- Se `Non si vede`, aggiungi una nota (es. browser/dispositivo/pagina).
- Quando hai finito, mandami i TTF dei font segnati come non visibili.
