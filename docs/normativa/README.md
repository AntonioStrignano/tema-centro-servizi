# Schede Normative

Ogni file in questa cartella descrive **una singola norma** che impatta il sito web delle scuole paritarie.

Per ogni norma trovi:
- Cos'è e cosa dice
- Chi è obbligato
- Cosa deve esserci sul sito
- Sanzioni previste
- Stato attuale nel tema

> Questa cartella è esclusa dal repository git (vedi `.gitignore`).
> È documentazione interna di riferimento per il webmaster.
